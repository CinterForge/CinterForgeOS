Run ./install.sh in CinterForgeOS KDE Konsole, from the unpacked folder.
The installer places 2 KDE launchers on ~/Desktop and 2 executable scripts
in ~/.local/share/cinterforge/demo-launchers.

Screenshot-confirmed directories:
 Linux:   steamapps/common/CinterForge/Applications/Linux/Heaven
 Windows: steamapps/common/CinterForge/Applications/Windows/Heaven/2026/app

Executable names and Proton 11.0 (ARM64) location are retained from the
previously supplied commands; the screenshot does not verify those files.
These launchers both target Heaven; the Windows demo is NOT Superposition.
